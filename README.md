# Crypto Dashboard

Projeto de um dashboard de criptomoedas desenvolvido com **JavaScript**, **HTML**, **CSS** e integração com APIs externas para consulta de preços em tempo real. O sistema permite pesquisar, filtrar e acompanhar informações de diferentes ativos digitais por meio de uma interface simples, responsiva e organizada.

## Objetivo

Este projeto foi criado com o intuito de praticar:

* Consumo de APIs REST
* Manipulação assíncrona de dados com JavaScript
* Estruturação de aplicações front-end modulares
* Implementação de filtros e mecanismos de busca
* Organização de código seguindo boas práticas de desenvolvimento

## Tecnologias Utilizadas

* JavaScript (ES6+)
* HTML5
* CSS3
* API de Criptomoedas
* Fetch API

## Funcionalidades

* Consulta de preços de criptomoedas em tempo real
* Busca dinâmica por nome da moeda
* Filtros para exibição de ativos específicos
* Atualização automática dos dados consumidos da API
* Exibição organizada das principais informações do mercado

## Destaques Técnicos

* Integração com API externa utilizando **Fetch API**
* Manipulação assíncrona com **async/await**
* Separação de responsabilidades através da modularização do código
* Organização de arquivos por funcionalidades
* Tratamento básico de erros em requisições HTTP
* Estrutura preparada para expansão de novas funcionalidades
* Código reutilizável e de fácil manutenção


## Boas Práticas Aplicadas

* Modularização de responsabilidades
* Reutilização de funções e componentes
* Separação entre lógica de negócio e interface
* Nomenclatura consistente de variáveis e funções
* Uso de constantes para configurações e endpoints
* Redução de duplicação de código
* Facilidade para manutenção e escalabilidade

## Aprendizados

Durante o desenvolvimento deste projeto, foram reforçados conceitos como:

* Consumo e tratamento de dados provenientes de APIs
* Programação assíncrona com JavaScript moderno
* Manipulação dinâmica do DOM
* Implementação de filtros e pesquisas em tempo real
* Estruturação de projetos front-end de forma organizada
* Aplicação de boas práticas de desenvolvimento e manutenção de código
